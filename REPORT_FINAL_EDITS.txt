B1. DEAN: LHAR FORMULA STILL DOES NOT MATCH THE IMPLEMENTED CODE

WHERE: Section 3.1, PDF page 7 / printed page 6, under "Incorporating Asymmetries: The Leverage LHAR Model".

The current formula takes the negative part of each daily return BEFORE averaging. The code averages SIGNED returns first, THEN takes the magnitude of a negative average. It also uses positive magnitudes, rather than signed negative inputs. This is a model-description correction, not just a style preference.

PROPOSED ACTION: replace the whole block from "Because negative equity returns induce" through "to isolate market-wide panic spillovers", including its current formulas. Stop before Section 3.2.

PLAIN-TEXT REPLACEMENT:

PASTE START
Negative equity returns may contain information about future variance beyond the size of past price movements. Motivated by the persistent-leverage approach of Corsi and Renò (2012), the LHAR adds three measures of negative ES returns over 1, 5 and 22 observations. Let r_t be the decimal ES close-to-close log return, obtained by dividing the dataset's percentage return by 100. For each window, the leverage input is the magnitude of the negative part of its average signed return:

d_t^(h) = |min(mean(r_t, ..., r_(t-h+1)), 0)|, for h = 1, 5 and 22.

If the average return is negative, the measure equals its magnitude; otherwise, it is zero. Gains and losses can therefore offset each other before the negative part is taken. These three variables are added to the HAR's variance regressors, using only returns observed before the forecast target. The resulting model is called LHAR. The coefficients are estimated from the data, so a negative return does not automatically increase the forecast. This is the same construction used for the LVAR leverage inputs in Section 3.3.
PASTE END
